PUT Roll-Down: Does It Work?

Every Bitmor loan is hedged with a PUT option. As monthly payments reduce the debt, the PUT strike becomes too high — so we sell it and buy a cheaper one at the lower strike, pocketing the difference as roll savings. These backtests measure how much of the initial PUT premium can be recovered through this strategy across 2,000+ historical and simulated loans.

Higher recovery = lower effective hedging cost. How the roll-down works →

Monthly Payment (Annuity)

Each loan has a fixed monthly payment sized conservatively at origination using the maximum possible borrow APR:

A = P × r(1 + r)n / ((1 + r)n − 1) // standard annuity
where P = principal, r = r_max / 12, n = months
pay_one = min(A, debt_remaining) // never overpay

Actual interest accrues at the live variable rate via Aave-style indices; the schedule provides predictable cash-flow and a conservative bound. Try different terms above →

Interest Rate Model

Bitmor uses a two-slope utilization curve, similar to Aave. Low utilization keeps rates affordable; high utilization incentivizes new deposits:

Virtual Utilization = Total Borrowed / (Bitmor Balance + Aave Position) // includes idle funds in Aave

Idle USDC is deployed to Aave V3 for yield, but utilization is calculated on the full pool — borrowers aren't penalized for idle liquidity sitting in Aave.

Reference

Backtest Methodology

How the roll-down backtest and simulation work, from strategy mechanics to data sources.

Strategy Overview

PUT struck at debt level. As payments reduce debt, sell the old PUT (strike too high), buy cheaper one at new lower strike. Difference = roll savings. Only rolls when profit > $200.

See a live example →

Roll Decision

Monthly checkpoints (months 1–11). Reprice held PUT via IV surface, compare to replacement at current debt. Roll only if net gain > $200. Accumulated as roll savings.

Premium Recovery

Recovery % = cumulative roll savings / initial premium. Higher = cheaper hedge. See results →

Option Pricing

Black-Scholes for European cash-settled PUTs. Inputs: spot, strike (= outstanding debt), time to expiry, IV from SVI surface. Risk-free rate = 0.

IV Surface

Deribit historical trades, 700+ days. SVI parameterization per day across 5 tenor buckets (short/90d/180d/270d/365d). Arbitrage-free, 26 moneyness points. Min 6 quotes per day-tenor; sparse buckets forward-filled up to 60 days.

GBM Calibration

Geometric Brownian Motion. Drift & vol from ~3 years Binance BTCUSDT hourly data, resampled to daily log returns. Daily resolution (dt = 1/365). IV surface frozen at latest snapshot for forward months.

Key Assumptions

  • Frozen IV: Forward months use today's IV snapshot (conservative).
  • No fees: No exchange fees applied. Real recovery slightly lower.
  • Monthly only: 11 roll checkpoints per loan.
  • Constant GBM: No regime shifts modeled.

Data Sources

Spot: Binance BTCUSDT hourly, ~3 years. Options: Deribit historical trades, ~1.4M data points, 700+ days.
